## Task title

Vosk Model Setup and Local Recognition Gate

## Goal

Добавить безопасную проверку настройки модели Vosk и gate локального
распознавания, чтобы JARVIS мог объяснить, готово ли локальное распознавание к
будущему включению.

## What was added

- `voice/vosk_local_recognition_gate.py`
- Проверка доступности Python-пакета `vosk` без импорта Vosk.
- Проверка настроенного пути к модели Vosk.
- Безопасное отображаемое значение пути для пользователя.
- Gate-результат с `allowed`, блокировками, предупреждениями, сообщением и
  следующими шагами.
- Unit-тесты для gate.
- Документация `docs/VOSK_MODEL_SETUP.md`.

- Подключение `CONTINUOUS` к реальному распознаванию.
- Фоновые слушатели.
- Бесконечные циклы.
- Загрузка больших моделей Vosk в тестах.
- Автоматические скачивания.
- Автоматические установки пакетов.
- Запись аудио на диск.
- Отправка аудио в облако.

## Vosk setup checks

Gate проверяет:

- доступен ли пакет `vosk`;
- указан ли путь к модели;
- какое безопасное значение пути показать пользователю;
- существует ли путь;
- является ли путь папкой.

## Recognition gate behavior

Локальное распознавание разрешается только если:

- пакет `vosk` доступен;
- путь к модели настроен;
- путь существует;
- путь является папкой;
- включение требует явного разрешения пользователя;
- микрофон не запускается автоматически;
- распознавание не является непрерывным.

Если условие не выполнено, gate возвращает русскоязычные блокировки и
следующие шаги.

## Russian-first behavior

Основные пользовательские сообщения:

- `Локальное распознавание Vosk пока недоступно.`
- `Пакет vosk не установлен.`
- `Путь к модели Vosk не указан.`
- `Папка модели Vosk не найдена.`
- `Локальное распознавание может быть включено только после явного разрешения пользователя.`
- `Автоматический запуск микрофона не выполняется.`
- `Постоянное прослушивание пока не связано с реальным распознаванием.`

## Safety rules

Gate не импортирует Vosk, не загружает модель, не вызывает one-shot захват, не
запускает постоянное прослушивание, не создает потоки, не скачивает модели и не
устанавливает пакеты.
