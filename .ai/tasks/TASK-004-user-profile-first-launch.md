# TASK-004 — User Profile & First Launch Setup

## Роль Codex

Ты инженер-исполнитель проекта JARVIS OS.

Архитектурные решения не принимаешь самостоятельно.
Работаешь строго по задаче.

## Главный архитектурный принцип

JARVIS OS должен всегда оставаться расширяемой платформой.

Нельзя принимать решения, которые мешают в будущем добавить:

- голосовое управление;
- зрение экрана;
- память;
- human-like dialogue;
- workflow automation;
- installer;
- новые ИИ-модели;
- новые языки;
- плагины;
- новые идеи пользователя.

Любое изменение должно сохранять модульность проекта.

## Цель

Добавить локальный профиль пользователя и первое знакомство при первом запуске JARVIS OS.

JARVIS должен:

- при первом запуске спросить имя пользователя;
- спросить, как обращаться к пользователю;
- спросить, как пользователь хочет назвать ассистента;
- спросить язык общения;
- спросить основные сферы использования;
- спросить стиль общения;
- сохранить профиль локально;
- при следующих запусках не задавать вопросы повторно;
- приветствовать пользователя по сохранённому имени.

## Приватность

Профиль пользователя должен храниться локально.

Нельзя:

- отправлять профиль в интернет;
- использовать внешние API;
- добавлять облачную синхронизацию;
- сохранять лишние персональные данные;
- делать возраст обязательным.

Возраст можно спросить только как необязательное поле.

## Нужно реализовать

### 1. UserProfileManager

Создать файл:

users/user_profile.py

В нём создать класс:

UserProfileManager

Он должен уметь:

- проверять, существует ли профиль;
- создавать профиль;
- загружать профиль;
- сохранять профиль в JSON;
- возвращать имя пользователя;
- возвращать имя ассистента;
- возвращать язык;
- возвращать стиль общения.

Использовать только стандартные библиотеки Python:

- json
- pathlib
- datetime

### 2. Структура профиля

Профиль должен сохраняться в:

users/profiles/default_user.json

Пример структуры:

{
  "user_name": "Исмаил",
  "preferred_name": "Исмаил",
  "assistant_name": "JARVIS",
  "language": "ru",
  "age": null,
  "main_use_cases": [
    "документы",
    "автоматизация компьютера",
    "помощь в проектах"
  ],
  "communication_style": "естественный, понятный, не робот",
  "created_at": "...",
  "updated_at": "..."
}

### 3. First Launch Setup

При первом запуске, если профиль отсутствует, JARVIS должен вывести:

Здравствуйте. Я JARVIS.
Давайте познакомимся.

И спросить:

- Как вас зовут?
- Как мне к вам обращаться?
- Как вы хотите назвать ассистента?
- Какой язык использовать? По умолчанию ru.
- Хотите указать возраст? Это необязательно.
- В каких сферах вы планируете использовать ассистента?
- Какой стиль общения вам удобен?

После этого сохранить профиль.

### 4. Повторный запуск

Если профиль уже существует:

- не задавать вопросы повторно;
- загрузить профиль;
- использовать preferred_name в приветствии.

Например:

[INFO] Добро пожаловать, Исмаил.

### 5. Kernel integration

JARVISKernel должен уметь принимать user_profile.

Приветствие не должно быть жёстко зашито как "Исмаил".

Нужно использовать имя из профиля.

Если профиль не передан, использовать безопасное значение по умолчанию:

Пользователь

### 6. run.py

run.py должен:

- создать UserProfileManager;
- проверить наличие профиля;
- если профиля нет — запустить первое знакомство;
- загрузить профиль;
- передать профиль в JARVISKernel;
- запустить Kernel.

### 7. Tests

Добавить tests/unit/test_user_profile.py

Тесты должны проверять:

- создание UserProfileManager;
- отсутствие профиля;
- сохранение профиля;
- загрузку профиля;
- получение имени пользователя;
- получение имени ассистента;
- необязательный возраст;
- корректную работу без внешних библиотек.

Обновить tests/unit/test_kernel.py при необходимости.

## Проверки

После изменений должны проходить команды:

python -m py_compile users/user_profile.py
python -m py_compile core/kernel.py
python -m py_compile run.py
python -m tests.unit.test_user_profile
python -m tests.unit.test_kernel

При первом запуске должна провести знакомство.

При повторном запуске должна сразу запустить JARVIS и приветствовать пользователя по имени.
