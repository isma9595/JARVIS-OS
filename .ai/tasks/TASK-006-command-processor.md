# TASK-006 — Command Processor

## Роль Codex

Ты инженер-исполнитель проекта JARVIS OS.

Архитектурные решения не принимаешь самостоятельно.
Работаешь строго по задаче.

## Главный архитектурный принцип

JARVIS OS должен всегда оставаться расширяемой платформой.

Нельзя принимать решения, которые мешают в будущем добавить:

- голосовое управление;
- зрение экрана;
- память;
- workflow automation;
- installer;
- новые ИИ-модели;
- новые языки;
- плагины;
- новые идеи пользователя.

Любое изменение должно сохранять модульность проекта.

## Цель

Добавить Command Processor — слой понимания простых текстовых команд пользователя.

На этом этапе JARVIS НЕ должен управлять компьютером.
Он только принимает текстовую команду, определяет намерение и возвращает понятный ответ.

## Нужно реализовать

### 1. CommandProcessor

Создать или обновить файл:

core/command_processor.py

В нём создать класс:

CommandProcessor

Он должен принимать:

- user_profile
- dialogue_manager

Если user_profile или dialogue_manager отсутствуют, использовать безопасные значения по умолчанию.

### 2. Метод process

CommandProcessor должен иметь метод:

process(command_text)

Он принимает строку команды и возвращает словарь:

{
  "intent": "...",
  "response": "...",
  "should_exit": false
}

### 3. Поддерживаемые команды

Нужно поддержать простые команды на русском языке.

#### Команды о пользователе

Команды:

- кто я
- как меня зовут
- мое имя
- моё имя

Ответ должен использовать preferred_name из профиля.

Пример:

Исмаил, вы сохранены в профиле как Исмаил.

Intent:

user.identity

#### Команды об ассистенте

Команды:

- как тебя зовут
- кто ты
- твое имя
- твоё имя

Ответ должен использовать assistant_name из профиля.

Пример:

Меня зовут JARVIS. Я ваш персональный ассистент.

Intent:

assistant.identity

#### Команды профиля

Команды:

- покажи профиль
- мой профиль
- профиль

Ответ должен кратко показать:

- имя пользователя;
- имя ассистента;
- язык;
- стиль общения;
- основные сферы использования, если есть.

Intent:

user.profile

Важно:

Не показывать лишние чувствительные данные.
Возраст показывать только если он есть.

#### Команды возможностей

Команды:

- что ты умеешь
- помощь
- команды
- help

Ответ должен кратко перечислить текущие возможности:

- запуск ядра;
- профиль пользователя;
- естественный диалог;
- простые текстовые команды.

И отдельно сказать, что голос, зрение экрана и автоматизация будут добавлены позже.

Intent:

assistant.capabilities

#### Команды выхода

Команды:

- выход
- стоп
- остановись
- завершить
- закрыть

Ответ:

Хорошо, Исмаил. Завершаю работу.

Intent:

system.exit

should_exit:

true

#### Неизвестная команда

Если команда неизвестна, вернуть:

Intent:

unknown

Ответ:

Исмаил, я пока не умею выполнять эту команду, но могу запомнить её как идею для будущего.

should_exit:

false

### 4. Нормализация команд

CommandProcessor должен:

- убирать пробелы в начале и конце;
- приводить команду к нижнему регистру;
- нормально работать с пустой строкой.

Если команда пустая:

Intent:

empty

Ответ:

Исмаил, я не услышал команду. Повторите, пожалуйста.

### 5. DialogueManager

Если нужно, добавить методы для естественных ответов:

- identity_response()
- assistant_identity_response()
- unknown_command_response()
- empty_command_response()
- exit_response()
- capabilities_response()
- profile_response()

Но не усложнять.

### 6. Kernel integration

JARVISKernel должен создавать CommandProcessor как системный сервис.

Добавить сервис:

- command_processor

Метод get_service("command_processor") должен возвращать CommandProcessor.

Старые сервисы должны продолжить работать:

- logger
- event_bus
- module_manager

### 7. run.py interactive loop

После запуска Kernel run.py должен перейти в простой текстовый режим.

Пример:

Введите команду для JARVIS. Для выхода напишите: выход

Пользователь вводит команду.

JARVIS отвечает.

Если should_exit = true, JARVIS вызывает shutdown() и завершает программу.

Важно:

- цикл должен быть простым;
- не использовать внешние библиотеки;
- не выполнять системные команды;
- не пытаться управлять ПК;
- не ломать запуск.

Добавить tests/unit/test_command_processor.py

Тесты должны проверять:

- создание CommandProcessor без профиля;
- создание CommandProcessor с профилем;
- команду "кто я";
- команду "как тебя зовут";
- команду "покажи профиль";
- команду "что ты умеешь";
- команду "выход";
- неизвестную команду;
- пустую команду;
- should_exit для команды выхода;
- intent для каждой команды.

Обновить tests/unit/test_kernel.py:

- проверить get_service("command_processor");
- проверить, что неизвестный сервис всё ещё вызывает KernelError.

Должна вывести запуск JARVIS и перейти в режим команд.

Пример:

[INFO] Инициализация ядра...

[INFO] EventBus: OK
[INFO] ModuleManager: OK
[INFO] Система успешно запущена.

Введите команду для JARVIS. Для выхода напишите: выход

Если пользователь вводит:

кто я

Исмаил, вы сохранены в профиле как Исмаил.

Если пользователь вводит:

выход

JARVIS отвечает примерно:

Хорошо, Исмаил. Завершаю работу.

И завершает Kernel.
