# TASK-001 — Core Runtime Hardening

## Роль Codex

Ты инженер-исполнитель проекта JARVIS OS.

Архитектурные решения не принимаешь самостоятельно.

Работаешь строго по задаче.

## Цель

Усилить ядро модульной системы JARVIS OS.

## Разрешённые зоны изменений

Можно изменять только:

- core/base_module.py
- core/module_manager.py
- core/event_bus.py
- tests/unit/test_module_manager.py
- tests/unit/test_event_bus.py

Можно создавать только новые unit-тесты внутри:

- tests/unit/

## Запрещено

Нельзя:

- менять структуру папок;
- удалять файлы;
- менять документацию;
- менять memory;
- менять brain;
- менять security;
- менять integrations;
- добавлять внешние библиотеки;
- принимать архитектурные решения вне задачи.

## Требования к BaseModule

Добавить или проверить:

- строгие статусы жизненного цикла:
  - created
  - initialized
  - running
  - stopped
  - unloaded
- запрет неправильных переходов статусов;
- валидацию module_id;
- валидацию name;
- паспорт модуля;
- permissions;
- dependencies;
- supported_languages;
- get_info();
- get_status();

## Требования к ModuleManager

Добавить или проверить:

- регистрацию модулей;
- запрет повторной регистрации;
- проверку, что объект является BaseModule;
- запуск всех модулей;
- остановку всех модулей;
- получение модуля по ID;
- список модулей;
- корректную ошибку при неизвестном модуле.

## Требования к EventBus

Добавить или проверить:

- subscribe;
- publish;
- list_events;
- защита от ошибки одного callback;
- возможность нескольких подписчиков на одно событие.

## Требования к тестам

Тесты должны проверять поведение через assert.

Не просто print.

Нужно проверить:

- создание BaseModule;
- жизненный цикл BaseModule;
- ошибочный переход статуса;
- регистрацию модуля;
- повторную регистрацию;
- запуск модуля через ModuleManager;
- публикацию события через EventBus;
- работу нескольких подписчиков;
- ошибку одного подписчика без падения всей системы.

## Проверки

После изменений должны проходить команды:

python -m py_compile core/base_module.py
python -m py_compile core/module_manager.py
python -m py_compile core/event_bus.py
python -m tests.unit.test_module_manager
python -m tests.unit.test_event_bus
