# Versioning System

JARVIS OS использует систему версий.

Каждое важное изменение должно создавать новую версию.


Пример:

v0.1

Фундамент проекта.


v0.2

Добавлено ядро.


v0.3

Добавлена память.


# Типы версий


## Configuration Version

Настройки системы.


## Memory Version

Состояние памяти.


## Module Version

Версии модулей.


## System Snapshot

Полная точка восстановления.
