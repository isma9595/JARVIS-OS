# Пробный запуск локального распознавания Vosk

TASK-031 добавляет безопасный dry run для будущего локального распознавания Vosk.
Это не реальное распознавание речи. Это проверка маршрута: gate готовности,
тестовые данные, stub-распознаватель и русскоязычный ответ пользователю.

## Что означает dry run

Dry run отвечает на четыре вопроса:

- разрешает ли текущий gate локальное распознавание;
- может ли fake/stub операция распознавания завершиться;
- какие блокировки мешают пробному запуску;
- какое русское сообщение нужно показать пользователю.

Если gate блокирует путь, JARVIS возвращает безопасный заблокированный результат.
Если gate разрешает путь, JARVIS запускает только fake/stub распознаватель на
тестовых данных.

## Команды

- `пробный запуск vosk`
- `тест vosk`
- `тест распознавания`
- `пробное распознавание`
- `проверить локальное распознавание`
- `dry run vosk`

Ответ всегда сообщает:

- выполнен ли пробный запуск;
- разрешил ли gate выполнение;
- какие есть причины блокировки;
- что использовались тестовые данные;
- что реальный микрофон не запускался;
- что настоящая модель Vosk не загружалась;
- что реальное распознавание не запускалось.

## Что проверяется

Dry run использует существующую безопасную проверку готовности Vosk:

- установлен ли пакет `vosk` по metadata-проверке;
- указан ли путь к модели;
- существует ли путь;
- является ли путь папкой;
- включены ли безопасные ограничения: явное разрешение, отсутствие
  автоматического запуска микрофона и отсутствие связи `CONTINUOUS` с реальным
  распознаванием.

## Что не выполняется

Пробный запуск намеренно не делает следующее:

- не запускает микрофон;
- не вызывает one-shot аудиозахват;
- не включает постоянное прослушивание;
- не запускает фоновые потоки;
- не загружает настоящую модель Vosk;
- не импортирует Vosk для распознавания;
- не скачивает модели;
- не устанавливает Python-пакеты;
- не записывает аудио на диск;
- не отправляет аудио в облако;
- не меняет настройки автоматически.

В unit-тестах настоящая модель Vosk не загружается. Тесты используют fake gate и
fake recognizer, поэтому реальный микрофон и реальные файлы модели не нужны.

## Будущий шаг

Следующий этап может подключить one-shot захваченное аудио к локальному Vosk
распознаванию только после успешных gate-проверок, отдельного архитектурного
решения и явного разрешения пользователя. TASK-031 этого не включает.
