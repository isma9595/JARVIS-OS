# ADR-0001

## Название

Память хранится по смыслу, а не по истории сообщений.

---

## Проблема

История сообщений плохо подходит
для долгосрочного персонального помощника.

Пользователь вспоминает разговоры по смыслу,
а не по точным словам.

---

## Решение

Создать многоуровневую систему памяти:

- Рабочая память
- Контекстная память
- Семантическая память
- Эпизодическая память
- Память личности
- Память проектов

---

## Последствия

Система станет сложнее.

Но JARVIS сможет вспоминать знания,
а не искать совпадения по словам.
