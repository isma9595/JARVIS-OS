# Vosk: инструкция по ручной установке

TASK-020 не устанавливает Vosk и не меняет Python-окружение. Все команды ниже —
только справочный текст для ручного выполнения пользователем.

## Совместимость

Официальная инструкция Vosk указывает Python 3.5–3.9 и pip 20.3 или новее.
Текущая версия Python вне этого диапазона может оказаться несовместимой даже
при успешной установке пакета.

Рекомендуемый вариант — вручную создать отдельный venv на совместимой версии
Python. Не следует устанавливать Vosk в основное окружение JARVIS вслепую.

После активации отдельного окружения справочная команда установки:

```text
python -m pip install vosk
```

JARVIS эту команду не выполняет.

## Русская модель

Для первого lightweight-прототипа рекомендуется `vosk-model-small-ru-0.22`.
Модель следует вручную найти в официальном каталоге моделей Vosk, проверить
источник, скачать, распаковать в отдельную локальную папку и указать этот путь
в настройках JARVIS.

JARVIS не скачивает, не распаковывает и не загружает модель в runtime.

## Границы TASK-020

- Нет автоматической установки или создания venv.
- Нет импорта и запуска Vosk runtime.
- Нет доступа к микрофону или записи звука.
- Нет отправки пользовательских данных в интернет.
- Проверка версии Python носит только информационный характер.
