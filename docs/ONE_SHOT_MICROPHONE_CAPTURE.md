# Одноразовый захват микрофона

## Назначение

Одноразовый захват микрофона - это безопасная внутренняя основа для будущей
голосовой команды: пользователь явно просит принять одну команду, JARVIS
захватывает короткий фрагмент аудио один раз и сразу останавливается.

В TASK-027 добавлена только основа захвата аудио. Распознавание речи,
обработка голосовой команды и подключение Vosk намеренно не активированы.

## Почему это безопаснее непрерывного слушания

- захват запускается только явным вызовом метода;
- импорт модулей, создание класса, проверка статуса и переключение режимов не
  открывают реальный микрофон;
- длительность ограничена: по умолчанию 5 секунд, жесткий максимум 15 секунд;
- выполняется только одна попытка захвата;
- фоновые слушатели, потоки, бесконечные циклы и автоматический доступ к
  устройству не создаются;
- после попытки захват завершается.

## Что включено

- `OneShotMicrophoneCapture` - контролируемый сервис одноразового захвата;
- безопасная проверка доступности аудиоадаптера;
- проверка длительности до обращения к адаптеру;
- структурированный результат с русским пользовательским сообщением;
- внедрение адаптера для тестов без реального микрофона;
- режимная защита: фактический захват разрешен только в `PARTIAL`.

Пример результата:

```python
{
    "success": True,
    "available": True,
    "duration_seconds": 5.0,
    "audio_captured": True,
    "message": "Одноразовый захват микрофона завершен.",
    "error": None,
}
```

## Что намеренно не включено

- микрофон не запускается автоматически при старте JARVIS-OS;
- `CONTINUOUS` не подключен к реальному непрерывному захвату;
- Vosk не активирован и не вызывается;
- распознавание речи пока не выполняется;
- аудио не сохраняется на диск по умолчанию;
- аудио никуда не отправляется;
- зависимости не скачиваются и не устанавливаются автоматически.

Пользовательские сообщения остаются русскими по умолчанию:

- "Одноразовый захват микрофона недоступен: не найден аудиоадаптер."
- "Одноразовый захват микрофона завершен."
- "Микрофон не был запущен автоматически."
- "Реальное распознавание речи пока не активировано."

## Режимы

`OFF` означает, что захват не запускается. Для будущего сценария явной
голосовой команды поток должен сначала перейти в контролируемый `PARTIAL`, а
затем вызвать одноразовый захват.

`PARTIAL` разрешает один ограниченный захват по явному запросу.

`CONTINUOUS` остается только безопасным состоянием режима. В TASK-027 он не
запускает реальный микрофон, фоновые слушатели или непрерывное распознавание.

## Следующий шаг

Будущий этап может подключить результат одноразового захвата к Vosk после
отдельной настройки модели и отдельной проверки безопасности. Этот этап должен
оставаться явным, локальным и ограниченным одной командой.
## TASK-028: связь с Vosk пока не включена

One-shot захват микрофона остается отдельной безопасной основой. TASK-028 не
подключает его к Vosk и не запускает распознавание.

Будущая связь one-shot аудио с локальным Vosk распознаванием допустима только
после успешных gate-проверок, ручной настройки модели и явного разрешения
пользователя.
