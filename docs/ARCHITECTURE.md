# JARVIS OS Architecture

Версия: 0.2

Статус: Проектирование

---

## Цель проекта

Создать персональную интеллектуальную операционную систему,
которая сопровождает пользователя всю жизнь,
работает на разных устройствах,
поддерживает разные языки,
помнит контекст общения,
умеет принимать решения,
автоматизирует работу
и развивается вместе с пользователем.

---

## Главные принципы

1. Модульная архитектура.
2. Локальная работа по умолчанию.
3. Облачная синхронизация как дополнительная возможность.
4. Память хранит смысл, а не историю сообщений.
5. Пользователь полностью контролирует свои данные.
6. Любой модуль можно заменить без переписывания всей системы.
