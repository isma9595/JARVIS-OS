# Режимы прослушивания микрофона

## Зачем нужны режимы

JARVIS-OS должен поддерживать голосовое управление без потери контроля со
стороны пользователя. Режимы микрофона разделяют состояние системы и реальный
захват звука: код может явно знать, разрешено ли слушание, но само включение
устройства остается отдельным будущим шагом.

## OFF

`OFF` - безопасный режим по умолчанию.

- микрофон считается отключенным;
- слушание не разрешено;
- распознавание речи не должно запускаться;
- режим не требует активации, потому что ничего не слушает.

## PARTIAL

`PARTIAL` - режим одного явного голосового действия.

- JARVIS может перейти в состояние ограниченного слушания только после явной
  команды пользователя;
- режим предназначен для одного запроса или одной команды;
- после обработки команды система может вернуться в `OFF` или остаться в
  явно заданном пользователем состоянии;
- в рамках TASK-025 этот режим не запускает реальный микрофон автоматически.

## CONTINUOUS

`CONTINUOUS` - состояние, в котором JARVIS может быть готов к непрерывному
прослушиванию только после явного разрешения пользователя.

В TASK-025 это только безопасный флаг состояния. Он не включает постоянный
захват звука, не запускает фоновый слушатель и не подключает Vosk к
непрерывному распознаванию.

## Почему непрерывное слушание не включается автоматически

Постоянный микрофон влияет на приватность, безопасность и доверие к системе.
Поэтому непрерывный режим не должен запускаться при старте JARVIS-OS, при
импорте модулей, при создании менеджера состояния или при переключении флага.
Любое будущее включение реального микрофона должно быть отдельным явным
действием пользователя.

## Правила контроля пользователя

- режим по умолчанию всегда `OFF`;
- переход в `PARTIAL` или `CONTINUOUS` выполняется только явным изменением
  состояния;
- неизвестные режимы отклоняются;
- состояние режима не открывает устройство микрофона;
- пользователь должен видеть и контролировать, когда слушание разрешено.

## Правила безопасности

- нет фоновых потоков;
- нет бесконечных циклов прослушивания;
- нет доступа к устройству микрофона;
- нет автоматического старта захвата звука;
- нет автоматической активации Vosk;
- `CONTINUOUS` остается только контролируемым состоянием до отдельного
  одобренного этапа.

## Будущая интеграция с Vosk и микрофоном

Следующие этапы могут подключить реальные компоненты только после отдельного
одобрения:

1. связать режимы с безопасным UI/CLI-переключателем;
2. добавить явную команду одноразового прослушивания для `PARTIAL`;
3. добавить отдельное подтверждение для входа в `CONTINUOUS`;
4. подключить Vosk к одноразовому распознаванию;
5. только после проверки безопасности рассмотреть управляемое непрерывное
   распознавание.

## TASK-026: текстовые команды управления режимом

JARVIS-OS теперь понимает безопасные русские текстовые команды для проверки и
переключения внутреннего режима микрофона. Эти команды меняют только состояние
`MicrophoneListeningModeManager`: реальный захват звука, доступ к устройству,
фоновые слушатели и Vosk не запускаются.

### Проверка статуса

- `статус микрофона`
- `режим микрофона`
- `какой режим микрофона`
- `микрофон статус`

Ответы:

- `OFF`: `Микрофон выключен.`
- `PARTIAL`: `Включено частичное прослушивание. JARVIS готов принять одну голосовую команду после явного запуска.`
- `CONTINUOUS`: `Включен режим постоянного прослушивания. Реальный захват микрофона пока не активирован в целях безопасности.`

### Переключение в OFF

- `выключи микрофон`
- `отключи микрофон`
- `отключи прослушивание`
- `выключи прослушивание`
- `стоп микрофон`

Команды переводят внутренний режим в `OFF` и возвращают: `Микрофон выключен.`

### Переключение в PARTIAL

- `слушай одну команду`
- `прими голосовую команду`
- `включи частичное прослушивание`
- `режим одной команды`
- `частичное прослушивание`

Команды переводят внутренний режим в `PARTIAL` и возвращают: `Включено
частичное прослушивание. Реальный захват микрофона пока не запускается
автоматически.`

`PARTIAL` означает только готовность состояния для будущего одноразового
захвата. В текущей версии JARVIS не открывает устройство микрофона и не
читает аудио.

### Переключение в CONTINUOUS

- `включи постоянное прослушивание`
- `слушай постоянно`
- `режим постоянного прослушивания`
- `включи постоянный микрофон`

Команды переводят внутренний режим в `CONTINUOUS` и возвращают: `Режим
постоянного прослушивания включен как безопасное состояние. Реальный микрофон
пока не запускается автоматически.`

`CONTINUOUS` остается только безопасным флагом состояния. Он не создает
потоки, циклы прослушивания, фоновые процессы и не активирует распознавание.

### Отключение постоянного режима

- `отключи постоянное прослушивание`
- `выключи постоянное прослушивание`
- `перестань слушать постоянно`

Команды возвращают режим в `OFF` и отвечают: `Микрофон выключен.`

### Правила безопасности

- Реальный микрофон намеренно не включается.
- Захват аудио не запускается автоматически.
- Vosk не импортируется и не активируется для распознавания.
- Фоновые слушатели, потоки и бесконечные циклы не создаются.
- Команды работают только с безопасным внутренним состоянием.
- Будущая многоязычная поддержка возможна, но текущие пользовательские команды
  остаются русскими по умолчанию.

### Будущие шаги

Следующий безопасный этап может добавить реальный одноразовый захват после
явного запуска и отдельного подтверждения. Управляемое постоянное прослушивание
должно оставаться более поздним этапом с отдельными проверками безопасности,
видимым контролем пользователя и явным одобрением.
