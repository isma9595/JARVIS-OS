Status meanings:

- `VERIFIED`: implementation, focused test evidence, and documentation/task evidence are present and consistent for the recorded scope.
- `PARTIAL`: some objective is implemented, but evidence, docs, or coverage are incomplete.
- `STALE`: documentation or test assumptions no longer match current code.

- `SUPERSEDED`: later architecture intentionally replaced or narrowed earlier implementation.
