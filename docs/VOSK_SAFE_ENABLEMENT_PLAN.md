# План безопасного подключения Vosk

1. Сверить версию и разрядность Python/Windows с требованиями.
2. Вручную создать отдельный совместимый venv.
3. Проверить pip 20.3 или новее.
4. Вручную установить пакет только в изолированное окружение.
5. Получить `vosk-model-small-ru-0.22` из официального источника.
6. Проверить архив и распаковать модель в отдельный локальный каталог.
7. Сохранить путь через существующий менеджер настроек.
8. Добавить отдельный runtime loader с контролируемыми ошибками и без
   неявных побочных эффектов.
9. Протестировать offline-распознавание на специально подготовленном файле без
   микрофона.
10. Реализовывать микрофонный адаптер отдельной задачей, только с явным
    разрешением пользователя.

## Обязательные защитные условия будущего runtime

- Dependency и модель проверяются до запуска.
- Основное окружение JARVIS не изменяется автоматически.
- Модель никогда не удаляется и не перезаписывается при проверке.
- Аудио остаётся локальным; сетевой fallback отсутствует.
- Ошибка совместимости безопасно отключает backend.
- Доступ к микрофону не следует из факта установки Vosk.

На этапе TASK-020 runtime, распознавание, микрофон, запись и сетевой обмен
остаются отключёнными.
